# 📚 PLSR – Peer Learning & Smart Resolution

> Empowering *Education for All* through real-time doubt sharing, smart resolution, and collaborative learning.

[🌐 Live App](https://plsr-psi.vercel.app) • [📦 Backend Repo](https://github.com/kishan-kumar-s-d-444/PLSR)

---

## 🚀 Overview

**PLSR** is a MERN stack-based web platform promoting **SDG 4 – Quality Education**. It enables students and teachers to connect, communicate, and resolve doubts in real-time. Built with **Socket.IO**, it ensures instant delivery of messages while maintaining context and class-wise confidentiality.

---

## 🌟 Key Features

- ✅ **Real-time Doubt Sharing**: Seamless 1-to-1 and subject-based discussions using WebSockets.
- 🧑‍🏫 **Class-Specific Messaging**: Messages are securely shared within class boundaries or relevant subjects.
- 🧠 **Role-Based Communication**: Differentiated logic for students and teachers.
- 📚 **Subject Channels**: Easily join and discuss subject-based topics.
- 💬 **Private & Public Threads**: Individual chats and subject forums.
- 🔐 **MongoDB Storage**: All doubts and messages are saved with timestamps and metadata.
